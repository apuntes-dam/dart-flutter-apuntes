# Dart & Flutter

Apuntes personales para aprender **Dart** y **Flutter**, organizados con la misma estructura que la unidad 1 de Programación: del concepto de programa hasta ejecutar y comprobar código.

!!! info "Cómo está organizado"
    Cada apartado responde a una pregunta: *qué es un programa*, *cómo se escribe en Dart*, *qué datos maneja*, *cómo se comprueba* y *cómo se convierte en una app con Flutter*.

| [Prácticas](u01/practicas.md) | Guía de prácticas de la unidad |

| [Aplicaciones Híbridas · Tema 1](tema1-ah/index.md) | 29 ejercicios de otro módulo, adaptados |

!!! note "Qué son Dart y Flutter"
    **Dart** es el lenguaje (tipado, orientado a objetos, con *null safety*). **Flutter** es un framework de interfaces escrito en Dart que genera apps para móvil, web y escritorio con un único código.
