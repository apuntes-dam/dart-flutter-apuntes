# U1: Primer programa en Dart

## 1. Contexto

Esta unidad introduce el análisis de problemas, la escritura de programas sencillos y las herramientas para ejecutarlos y comprobarlos. Se usa Dart como lenguaje y Flutter como destino práctico.

## 2. Objetivo de aprendizaje

Reconocer la estructura de un programa Dart e identificar y relacionar los elementos propios del lenguaje.

## 4. Contenidos

1. [Un programa](01-programa.md): algoritmo, pseudocódigo y su traducción a Dart.
2. [Práctica con el lenguaje](02-lenguaje.md): `main`, variables, operadores, entrada y comentarios.
3. [Tipos de datos](03-tipos.md): números, texto, booleanos, colecciones y conversiones.
4. [Pruebas](04-pruebas.md): `package:test`.
5. [Flutter: primera app](05-flutter.md).
6. [Bucles](06-bucles.md): `for`, `forEach`, `while`.
7. [Entorno](07-entorno.md): instalación, `flutter doctor` y problemas frecuentes.
