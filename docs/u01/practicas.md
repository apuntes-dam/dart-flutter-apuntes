# Prácticas

## P1. Preparar el entorno
Instala el SDK de Flutter (incluye Dart), ejecuta `flutter doctor` y crea `hola_mundo` con `dart create`. Imprime tu nombre.

## P2. Ejercicios progresivos de Dart
1. Pide dos números y muestra suma, resta, producto, división y división entera.
2. Convierte grados Celsius a Fahrenheit.
3. Declara una `const` con el IVA (0.21) y calcula el precio final de un producto.
4. Usa `int.tryParse` para que no falle si el usuario escribe texto.
5. Guarda tres nombres en una `List` y muéstralos con interpolación.

## P3. Proyecto con pruebas
Crea una función `esPar(int n)` y escribe al menos tres pruebas con `package:test`, incluido el caso `0`.

## P4. Primera app Flutter
Modifica el contador para que también tenga un botón de restar y no baje de 0.

!!! tip "Entrega"
    Sube cada práctica a un repositorio Git con commits pequeños y mensajes claros. No incluyas claves ni tokens.
